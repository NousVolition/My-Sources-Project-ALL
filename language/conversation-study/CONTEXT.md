# Confusion and context

[← Study home](README.md)

Manual contextual reading. Confusion describes expressed uncertainty, ambiguous references, or demonstrated request/answer mismatch; it is not a trait assigned to a participant.

This is one evolving conversation. An exact repeated request supplies a useful contrast but does not isolate history as the sole cause of the changed answer.
