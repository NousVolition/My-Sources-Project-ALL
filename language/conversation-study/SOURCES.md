## Reading rules

- **First_Source:** Explicit UI user markers plus date separators; repeated user headers are not counted twice.

- **Second_Source:** Embedded User/AI blocks are retained as reconstructions; later unmarked speaker boundaries are not auto-certified.

- **Partial:** The earliest original message and the complete conversation length remain unknown.

- **Duplicates:** All three raw snapshots remain byte-for-byte unchanged. The 565-line overlap is linked. UI echoes, embedded reconstructions, repeated tables, and displayed code are distinct occurrence types, not independent evidence.

- **Counts:** No full-conversation speech totals or prevalence claims. Later speaker boundaries are manually inferred locally and not fully certified. Whitespace totals include quotations and UI.

- **Analysis:** Selected overlapping categories and word paths; no intent score, personal diagnosis, or automatic classification ground truth.

- **Comparison:** New categories applied in new pass only; blanks in earlier panels do not imply absence.

- **Causality:** Sequence links do not prove causation, hidden programming, or motive.
