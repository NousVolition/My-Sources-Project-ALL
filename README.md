# SIMS evolving guards and asymmetric interaction

<a id="the-original-framework-and-its-tests"></a>

**SIMS evolving guard studies by [NousVolition](https://github.com/NousVolition)** examine changing interaction boundaries, unequal influence and individual responses. This repository preserves the original provisional framework, Navier–Stokes SIMS comparisons, moldable Hug studies and the source archive. Each study tests a specified component; the complete framework remains provisional.

Start with [Navier–Stokes SIMS and guard feedback](reports/sims-navier-stokes-guard/refinement/README.md), [equal and unequal influence with an active guard](reports/sims-active-guard/README.md), or [moldable Hug refinement](reports/hug-molding-refinement/README.md).
