# Source trajectories for gas return selection

This supporting subset contains the 12 original recorded trajectories used by the [return-selection experiment](../gas-return-selection-extension/README.md): nine runs (three starts by three damping levels), plus three finer recordings of start 2. They are byte-for-byte copies, verified against the source hashes in the experiment results.

The files retain their full original arrays and per-run configuration metadata. This directory supplies the analysis inputs; it is not a publication of all earlier gas-damping reports or a complete molecular-simulation regeneration pipeline.
